# Model Training - Linear Regression

## Overview

After preprocessing the dataset and splitting it into training and testing sets, the next step is to build the machine learning model. In this project, **Linear Regression** is used to predict the Human Development Index (HDI) based on the selected input features.

The model is trained using the training dataset so that it can learn the relationship between the independent variables (X) and the dependent variable (Y).

---

## Import the Required Library

```python
from sklearn.linear_model import LinearRegression
```

---

## Create the Linear Regression Model

```python
model = LinearRegression()
```

**Purpose:**
- Creates an instance of the Linear Regression model.
- Prepares the model for training.

---

## Train the Model

```python
model.fit(X_train, Y_train)
```

**Purpose:**
- Trains the model using the training dataset.
- Learns the relationship between the input features and the target variable.
- Generates a predictive model for HDI estimation.

---

## Test the Model

Use the testing dataset to generate predictions.

```python
Y_pred = model.predict(X_test)
```

**Purpose:**
- Predicts HDI values for the testing dataset.
- Compares predicted values with actual values.
- Evaluates how well the model performs on unseen data.

---

## Display Sample Predictions

```python
print(Y_pred[:5])
```

**Purpose:**
- Displays the first five predicted HDI values.
- Provides a quick overview of the model's predictions.

---

## Model Evaluation

Evaluate the performance of the Linear Regression model using regression metrics.

```python
from sklearn.metrics import mean_squared_error, r2_score

mse = mean_squared_error(Y_test, Y_pred)
r2 = r2_score(Y_test, Y_pred)

print("Mean Squared Error:", mse)
print("R² Score:", r2)
```

**Purpose:**
- **Mean Squared Error (MSE):** Measures the average squared difference between actual and predicted values.
- **R² Score:** Indicates how well the model explains the variation in the target variable. A value closer to **1** indicates better performance.

---

## Summary

The Linear Regression model is trained using the prepared training dataset and then tested using unseen data. Predictions generated by the model are evaluated using regression metrics such as **Mean Squared Error (MSE)** and **R² Score**, ensuring the model performs accurately before deployment.
